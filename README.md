# Mazurska Natura Bydła

**[Przejdź do strony projektu → mazurskanaturabydla.pl](https://mazurskanaturabydla.pl/)**

Grupa Operacyjna EPI „Mazurska Natura Bydła” łączy doświadczenie hodowców, wiedzę ekspertów i możliwości technologii cyfrowych. Wspólnie przygotowujemy rozwiązania wspierające zarządzanie stadem bydła mięsnego w ekstensywnym systemie wypasu na Warmii i Mazurach.

Nasze obszary działania to zdrowie i dobrostan zwierząt, wykorzystanie pastwisk i żywienie oraz cyfrowe wsparcie codziennych decyzji hodowcy.

Na stronie opisujemy projekt i współpracę grupy, publikujemy aktualności ze spotkań oraz udostępniamy dokumenty projektu.

- [Aktualności](https://mazurskanaturabydla.pl/aktualnosci/)
- [Dokumenty projektu i plan operacji](https://mazurskanaturabydla.pl/#dokumenty)
- Kontakt: [kontakt@mazurskanaturabydla.pl](mailto:kontakt@mazurskanaturabydla.pl)

Przygotowano w ramach umowy nr 00325.DOPI.65730.228.2026 o przyznaniu pomocy w ramach interwencji I.13.5 Współpraca Grup Operacyjnych EPI, Zakres Wsparcie Przygotowawcze.
